# Recursos del piloto Carnes

- `icons/`: selección de Phosphor Icons, variante regular, descargada sin modificar desde https://github.com/phosphor-icons/core/tree/main/assets/regular. Licencia MIT conservada en `icons/LICENSE`. Se aplican como máscaras con color del componente; no se importa ningún framework.
- `cattle-header.webp`: imagen ilustrativa generada para el encabezado de Carnes; no representa una explotación, productor ni establecimiento identificado. Archivo original conservado fuera del repositorio en la carpeta generated_images de Codex. Exportación WebP de 65.982 bytes.

La imagen es decorativa. No se utiliza para aportar información estadística ni identificar procedencia de observaciones.
